01 / INSTALLmacOS · Windows · Linux

Open your terminal. Start here.

$uv tool install git+https://github.com/4firas/MCPCord.git && mcpcord setup

Requires uv, Git and the Codex CLI; Python 3.11+ can be supplied by uv. Linux also needs secret-tool and an unlocked desktop keyring. On PowerShell 5, run the two commands separately.

Read the setup details ↗
02 / CONNECT LOCALLY

Your token goes in your terminal.

Acknowledge the personal-account risk, then enter your token in a hidden local prompt. It is stored in macOS Keychain, Windows Credential Manager or Linux Secret Service. Setup keeps an existing MCPCord registration and collects no messages.

One thing to know before connecting.

Automating a personal Discord account can violate Discord’s rules and put the account at risk. Read-only code does not remove that risk, and the credential itself is not read-scoped. MCPCord is independent of Discord.

04 / BEFORE YOU ASK

Fair questions.

Does it read every conversation I’ve ever had?+

No. Access depends on Discord, your permissions, and the reader’s configured limits. Closed or older DMs, deleted messages, and inaccessible channels may be missing. Active and archived threads and forum posts can be discovered separately. Discord may not return every private or older thread. An empty result is not proof that nothing happened.

What does “local” actually mean?+

The MCP reader runs on your computer and talks to Discord when a supported tool is called. Your credential stays with that local process. Returned message text can become part of your AI conversation; the model provider and MCP client determine what happens to that text.

Does it work with my AI app?+

Local Codex over STDIO MCP is verified. Reconnect MCP or open a new local session after setup. Other local STDIO clients can use mcpcord setup --no-register and configure the printed command; they have not been individually verified. No native cloud/dot attachment or scheduling is included.

Is this a Discord bot?+

No. This is an experimental reader for personal-account access, not a Discord-approved personal-inbox integration. Its Discord requests only read. That does not make the credential read-only or remove Discord’s account-policy risk.

Can it find a person or search old history?+

Yes. Use an exact user ID to separate authored messages, mentions, and replies. Discord search works one server or conversation at a time and may miss unindexed results. Explicit history imports collect selected channels in bounded, resumable slices. They stay in memory by default; saving content across restarts requires a separate opt-in.

What does activity analysis tell me?+

Message counts by day or hour in your chosen timezone, with sources. It does not track presence or infer someone’s location, availability, relationships, or personal traits. Missing messages leave gaps.

Can I use it with offline exports?+

There is a separate archive mode for explicitly supplied DiscordChatExporter JSON files. It reads those files without connecting to Discord. It only knows what is in the exports; Discord’s account-data package is a different format.
